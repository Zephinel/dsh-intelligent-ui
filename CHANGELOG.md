# Changelog

Notable changes to `@zephinel/dsh-intelligent-ui`. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions are the
published npm versions. `Unreleased` collects changes on `main` that have not
been published yet.

## [Unreleased]

### Added

- **Repeatable package-level release check (`npm run check:release`).** `scripts/release-check.mjs` packs the artifact, extracts the tarball's complete manifest, installs it into a throwaway `$DSH_HOME` (isolated Web instance on an OS-assigned port) and verifies what actually ships: every packed path exists in the checkout and `lib/`, `skills/`, `locale/` plus the bundle patch hash-match it; the installed package's file set and hashes are byte-identical to the tarball (references, standalone assets and the license/README files included); the packed Agent Skill carries the current policy wording and no retired wording; the composed loader row, the boot graph plus the served client bundle (vs. the installed file), and clean uninstall of the dependency, bundle row and package directory all pass. This closes the gap that let a rebuilt `lib/` reach a local profile while `skills/` stayed stale: `npm run check` never leaves the source tree, so it cannot see packaged or installed state. Requires the `dsh` CLI and pnpm on PATH; `npm pack` runs the repository's `prepare` build (rewriting the ignored `lib/`), and the script never reads or writes the user's profiles or the running service.

- **Experimental document answer mode (`documentMode`).** A new Plugin-detail-page **Experimental** switch renders an ordinary rendered answer as the turn's message text instead of a card: the prompt tells the model to write the whole answer as one free-layout document (ordinary prose/table/code blocks plus interactive blocks in reading order), pass `style: "free"` with no `styleId`/`temporaryStyle`, and write no Markdown reply; the Host enforces the free layout, ignores the session template for these renders, records `document: true` in the success value and result meta, and the client renders the recorded result as a chrome-less `section.dsh-iui-document` with no header, collapse control, editing entry or revision history. On-demand results, saved templates and Artifact edit requests keep their card contract. The mode is an explicit stopgap for in-message UI: the content still lives in the turn-tail result, so message copy/search/transcript Markdown export omit it, Web is the only renderer, and the removal path (delete the setting, prompt prefix/note, Host `documentRender` branch and client `DocumentCard` once DSH supports in-message UI natively) is documented in the architecture/limitations docs. **Also fixed:** ordinary `render_ui` results now record their resolved `style`/`styleSource` in `presentationMeta`, so a settled Auto free-layout page replays without a style identity (previously it was dropped on replay). Docs updated across README (both languages), architecture, usage, limitations, the development guide, the Agent Skill, the integration reference and troubleshooting; tests cover the prompt contract, Host enforcement, ordinary-result meta, client replay/extraction, the settings switch and a chrome-less document answer in the style-theme browser suite.
