## Highlights

- Fix an exponential-expansion issue in the bundled OpenUI parser by upgrading `@openuidev/lang-core` 1.0.1 → 1.1.1.
- Upgrade if you are on 0.6.0 or earlier.

## Details

0.6.1 is a security/availability patch: 0.6.0 and earlier bundled `@openuidev/lang-core@1.0.1`, whose `resolveRef()` did not memoize shared references, so a model-authored doubling-reference program could consume exponential time and memory in the synchronous Host parse. With 1.1.1 the bounded local reproduction of the N=18 program dropped from about 2.4 s / 466 MB to milliseconds. The residual unresolved-reference class noted upstream is out of scope for this patch.
