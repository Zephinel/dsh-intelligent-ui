## Highlights

- 渲染结果可以直接编辑：在卡片上选区块、写修改要求或调整顺序，提交前先看总预览；支持嵌套区块、批量结构操作、修订历史与删除回滚。
- Auto 不再默认生成页面：模型根据回答价值决定页面还是文字；选择页面时可自由布局，不再强制 Card/Article 外壳。
- 新增实验性「回答即文档」模式：开启后普通回答直接渲染为无卡片外壳的文档页面，读起来接近聊天正文。
- 渲染结果支持工作区本地图片（`Image` 与 Markdown），并能在图片导出和单文件 HTML 导出中正确内联。
- 编辑画布支持自然语言样式调整、内置/已保存模板的零模型样式切换，保留页面布局并记录为新修订。
- 新增侧栏版本更新提示：发现 npm 新稳定版时在 New Session 下方显示卡片，点击查看人工审核的中英文更新要点，点击卡片其余区域打开插件详情页。

## Details

0.6.0 是 0.5.0 之后的功能集合：渲染结果的就地编辑与修订管理、Auto 的页面/文字决策、文档模式、本地图片、样式切换、更新提示，以及配套的 Host 校验、导出语义、可访问性和测试/CI 加固。完整的逐项变更见仓库 `CHANGELOG.md` 的 0.6.0 条目。
