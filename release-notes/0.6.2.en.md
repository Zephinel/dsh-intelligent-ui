## Highlights

- The Plugins detail page no longer shows the full README; it shows a concise, language-matched settings guide covering the common switches, the experimental answer-as-document mode, and template/revision entry points, with links to the full docs.
- The README still serves GitHub, npm and the detailed documentation; in-plugin usage is unchanged.

## Details

0.6.2 adds `locale/detail.zh.md` / `locale/detail.en.md` and points `meta.detail` at them from `locale/*.json`; DSH reads that document first and only falls back to the package README. This release only changes what the plugin page displays; it does not change plugin behavior or configuration.
