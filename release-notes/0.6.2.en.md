## Highlights

- The Plugins detail page now shows a short bilingual setup guide instead of the whole README.
- The update notice is a prompt that appears when relevant: the first explicit enable only records a newer version, a later enable shows it, and Later / do-not-remind settle it per version; the sidebar card is gone.
- Fix `render_ui` calls dispatched inside `run_code` (PTC mode) showing no card and no export pill again; results recorded before this update replay as cards too.
- Includes the update-prompt trigger, close and storage-boundary fixes.

## Details

0.6.2 collects the changes on main since 0.6.1: the plugin-detail introduction now comes from `locale/detail.<lang>.md` (the README still serves GitHub and the npm page); the update notice moved from an always-on sidebar card to a staged prompt (an explicit plugin open records or shows it, a deployment-wide default-open start asks on page start, Later counts per version, Escape or an outside click settles it, and a missing or failing store keeps the cycle in memory for the page), and the sidebar DOM insertion is gone; the turn-tail extractor now walks `run_code` child calls, so a `render_ui` dispatched through PTC gets its card and export pill back (an on-demand turn still requires the top-level `temporaryStyle` call; the boundary is unchanged). Known limits: docs/limitations.md.
