## Highlights

- 修复内置 OpenUI parser 的指数展开问题：升级 `@openuidev/lang-core` 1.0.1 → 1.1.1，共享引用只解析一次；此前一个约 400 字节的生成程序就可能让 Host 卡住数秒甚至 OOM。
- 建议所有 0.6.0 及更早版本的用户升级；这是可用性修复，不涉及数据泄露。
- 发布流程的 registry 校验改为等待 npm 传播最多 10 分钟，避免发布成功却被误判为失败。

## Details

0.6.1 是安全/可用性补丁：0.6.0 及更早版本打包了 `@openuidev/lang-core@1.0.1`，其 `resolveRef()` 对共享引用没有 memoization，模型生成的 doubling 引用程序可在同步的 Host 解析阶段指数级消耗时间与内存。升级到 1.1.1 后，本地有界复现中 N=18 程序从约 2.4 秒 / 466 MB 降到毫秒级。上游指出的“未解析引用仍可能超线性”的残余类别不在本次修复范围内。
