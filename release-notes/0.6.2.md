## Highlights

- 插件详情页改用简短的中英设置指引，不再整页显示 README。
- 更新提示改为按需出现的浮层：首次打开只记录，之后提示；支持「下次再说」与按版本静默，不再常驻侧栏。
- 修复 `run_code`（PTC）内派发的 `render_ui` 不显示卡片和「导出」按钮的问题；此前记录的结果在更新后同样回放为卡片。
- 更新提示的触发、关闭与存储边界修复一并包含。

## Details

0.6.2 汇总 0.6.1 之后 main 上的改动：插件详情页的介绍改为 `locale/detail.<lang>.md` 的简短指引（README 仍服务 GitHub 与 npm 页面）；更新提示由常驻侧栏卡片改为分阶段浮层（显式打开插件时记录/提示，全局默认打开时启动提示，按版本累计「下次再说」，Escape 或点击外部关闭，无可用存储时本页内生效），并删除了向侧栏列插入 DOM 的实现；轮末提取器现在递归读取 `run_code` 子调用，因此 PTC 内派发的 `render_ui` 会重新出现卡片与「导出」药丸（按需轮次仍要求顶层调用携带 `temporaryStyle`，边界不变）。已知限制见 docs/limitations.md。
