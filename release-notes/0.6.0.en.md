## Highlights

- Rendered results are editable in place: select blocks, write change requests or reorder them, and review a total preview before applying; nested blocks, batch structure operations, revision history and deletion rollback are included.
- Auto no longer defaults to a page: the model decides whether a page or text serves the answer, and a chosen page can use a free layout without a forced Card/Article shell.
- A new experimental "answer as a document" mode renders an ordinary answer as a chrome-less document page that reads like chat prose.
- Rendered results can embed workspace-local images (`Image` and Markdown), with correct inlining in PNG and single-file HTML export.
- The edit canvas supports natural-language style changes and zero-model switches to built-in or saved templates, preserving the page layout as a new revision.
- A sidebar update card appears when a newer stable npm release exists; it shows the human-reviewed bilingual highlights, and clicking the rest of the card opens the plugin detail page.

## Details

0.6.0 collects the work since 0.5.0: in-place editing and revision management, the Auto page-vs-text decision, the document mode, local images, style switching, the update card, and the accompanying Host validation, export semantics, accessibility, test and CI hardening. See the 0.6.0 section of `CHANGELOG.md` for the itemized changes.
