## Highlights

- 解释类回答默认把图表、流程和小交互直接嵌进正文，和文字一起阅读；行程、看板、表单等独立页面仍在轮末以可编辑页面卡片交付。
- Auto 模式现在支持四种交付：纯文字、正文内嵌、轮末页面、内嵌说明加一张页面卡片；一次回答最多一张卡片，不重复内容。
- 全新的应用图标，插件页与更新提示共用同一标识。
- 中英文界面文案统一术语、补齐单复数，并去掉面向用户的内部术语。
- 自定义浮层在双指缩放时贴住可视区域，不再移出屏幕。

## Details

0.7.0 汇总 0.6.2 之后 main 上的改动：解释类回答默认保留 Markdown，需要图表、表格、流程或小交互时，模型把完整程序写入 `openui` 代码块，客户端在消息内直接渲染；行程、看板、工具、表单、游戏等独立页面仍由 `render_ui` 在轮末交付可编辑卡片。两者可以在同一回答里分工，但一次回答最多一张卡片、不重复内容；卡片 / 文章设置只决定独立页面的版式，文档模式与按需生成仍是卡片形态。应用图标换新，更新提示中的小标识同步。自定义浮层改为按可视区域（`window.visualViewport`）定位，双指缩放时不会被挤出屏幕。中英文界面文案按简明写作规范统一术语、补齐单复数、移除内部术语；README 改写为视觉优先的文档索引。已知限制见 docs/limitations.md。
