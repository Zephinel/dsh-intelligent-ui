# 使用指南

[English](usage.en.md) | [返回 README](../README.md)

本文是插件打开后的使用概览。实现细节、Host/Client 契约和完整边界见[架构与行为](architecture.md)。

## 打开开关

1. 在输入框右侧点 **UI** 控件，选择「仅本会话」；或发送 `/iui on`。
2. 正常情况下，下一条有结构的回答会在该轮末尾渲染成卡片。
3. 需要默认开启时，在 **插件详情页** 打开「在所有会话中启用」；全局设置只影响新会话。

开关关闭时模型看不到 `render_ui`，会直接回文字回答；重新打开即可。要强制出卡片（或模型仍然回了文字），可在开关已打开的会话里用 `/intelligent-ui` 显式调用技能。

## 提问

直接描述你要的页面和可交互部分，例如：

- 「帮我排一个上海两日游，要能勾选和调整」
- 「做一个 7 速自行车的换挡模拟器」
- 「把这几张表变成一个可以筛选的销售看板」
- 「介绍一下中国历史，要能按朝代展开」

回答是否使用页面由模型按内容判断：有结构、可视化、交互或计算价值时出页面，短回答或文字更合适时直接用 Markdown。出页面时的版式可以在 **UI → 显示样式** 里按会话选择 Card / Article，或交给 Auto（Card、Article 或自由布局）。

## 回答即文档（实验）

在**插件详情页 → 实验性功能**打开「回答即文档（实验）」后，普通回答出页面时不再显示卡片标题栏、折叠与边框，读起来就是这一轮的聊天正文。模型会把正文、标题、表格等普通内容与交互块写进同一个页面，并且不再额外输出 Markdown；适合“解释、分析、排查”这类应该像回答而不是交付物的页面。

注意：这是消息内嵌 UI 的过渡呈现——页面仍挂在轮末，复制、搜索和会话导出 Markdown 不包含页面正文；文档页没有卡片编辑入口与修订历史；只有 Web 渲染器（Web/Desktop）显示，TUI/headless 等不渲染插件卡片的客户端看不到内容。按需生成、保存模板与 Artifact 编辑请求仍按卡片渲染。开关只影响之后的回答，已生成的结果保持生成时的文档呈现；关闭后新回答恢复为 Card / Article 卡片。完整边界见[已知限制](limitations.md)。

## 图片

- 让 Agent 生成或截图后，直接在回答里引用工作区文件即可：图片路径可以是工作区相对路径（如 `figures/chart.png`），也可以是绝对路径。客户端通过 Host 的 workspace-files 读接口（与文件预览同一权限，可读工作区外绝对路径）读取图片，再以同源 Blob URL 渲染，不依赖本地 http 服务、不污染 PNG 导出的 canvas。
- 支持 PNG / JPEG / WebP / GIF；`data:image/…;base64` 小图（解码后 ≤512 KiB）也可以直接内嵌。本地文件上限 10 MiB、像素上限 40 MP（本地文件与内联 data 都从已识别的头预解析）；按文件内容嗅探格式，不看扩展名。
- 显式给出的图片加载失败时显示**错误占位**（缺失、过大、格式不支持等），不会再拿 alt 去搜一张无关照片；搜索图片只属于 `SearchImage` 组件。
- path/data 来源的 SVG 暂不支持（会显示错误占位）；`http(s)` 的 SVG URL 仍按浏览器 `<img>` 行为显示（不执行脚本）。`Markdown` 的 `![alt](路径)` 走同一套解析；沙盒 `HtmlView` 里的本地图片暂不支持。
- 本地图片在渲染时读取当前视图会话的工作区；工作区里文件被移动/删除后需重新渲染页面。导出的单文件 HTML 会把本地图片内联为 data URL，离线可看。
- 依赖 DSH 0.2.2 的 workspace-files 服务；旧 Host 或缺少该服务时，本地路径显示「当前 Host 不支持读取本地图片」占位，http(s)/data 图片不受影响。

## 编辑已渲染页面

- 点卡片标题栏的 **编辑** 进入编辑画布；根层可编辑区块会有淡色轨道光晕。
- 左侧编排列表与画布双向 hover 联动。每行右侧的 **更多** 菜单提供定位、编辑、复制、移动到…和删除；删除在菜单内二次确认。
- 点区块填写修改要求并 **Save**，请求会进入待发送列表；也可以拖拽或键盘 ↑/↓/Home/End 调整顶层顺序。
- 画布上方的 **顶层 / 嵌套区块** 切换用于编辑容器内部（`Col`/`Row`/`Box`/`Grid`/`Card`/`Section`/`Carousel`）的区块。
- 面板顶部的 **样式** 区（**更改样式**）提供两种方式，且与区块请求互斥：① **样式切换**——选择内置 Card/Article 或已保存模板；悬停即可本地预览主题与 Article 外壳，点「应用样式」由 Host 记录一条零模型修订（同一程序、只换样式身份与主题；临时样式页会转为已保存/内置样式，模板 directives 不会重排既有内容）。Article 要求页面带目录和章节，不满足时该目标会置灰并显示一行原因；每次只显示一条状态说明当前为什么可应用或不可应用；已填写说明时，折叠的样式行显示「样式说明待发送」，发送摘要也会增加「样式说明」。只有带 theme 的临时样式结果提供「保存为模板」；它创建新模板、不覆盖内置或已有模板，其他页面不受影响。内置/已保存模板结果不显示保存入口；不提供“更新原模板”或“复制已保存模板”入口。② **或用文字描述（由模型修改）**——用一句话描述视觉调整（≤2000 字）；发送后模型按说明调整样式（版式由 Host 强制保持，内容变动只会告警），记录为新的临时样式修订。支持新 Host 且可编辑的卡片不再显示底部「调整样式」按钮（旧 Host/不可编辑卡片保留回退；重定向的只读回退卡不显示 Save/Adjust）。
- `Divider`/`Spacer` 选中后是快捷调整：颜色/单位用插件自绘下拉，宽度/粗细/高度用插件自绘滑块，画布实时预览，应用后由 Host 记录修订，不调用模型。每个单位在行下和菜单里各带一句说明：默认表示不设置长度，px 是固定值，% 按容器比例（高度用 % 时父容器要有确定高度）。
- 复制/删除/移动等结构操作先进入本轮待执行队列（批量模式先保存批量草稿）；点底部 **应用** 打开总预览，确认后由 Host 一次性记录一条结构修订。排队、取消批量编辑和删除 chip 都不会丢失草稿；记录修订后仅含结构操作的 Apply 关闭草稿，同时含区块请求/整体说明/排序时剩余请求自动发送（输入框有正文时保留 chip 手动发送）。编辑中可开启 **严格保护**，拒绝未选中顶层区块的改动。
- 编辑 Header 的 **退出编辑** 关闭画布；卡片标题栏也有退出入口。区块内容请求、整体说明和排序仍以输入框 chip 携带，正常发送后生成新修订；结构操作通过 **应用** 的总预览记录，或者随混合 Apply 在结构修订后自动发送。
- 旧版本渲染的卡片不需要手动迁移：第一次打开编辑、修订历史或恢复时，客户端会自动把当前渲染内容登记为 Host 的权威基础，之后结构操作、历史与恢复即可用。若部署的 Host 较旧或登记失败，相关操作会回退到指令编辑或提示重新渲染页面。

## 编辑请求、草稿与修订

- 每个被编辑的 Artifact 在输入框里有一个 chip：`编辑 {title} · 修订 N · {摘要}`。
- 同一聊天可保留多份草稿（单画布激活）；一次发送最多合并 3 个 Artifact 的请求，每个 Artifact 独立生成修订。
- 删除 chip 只会把对应草稿从本次发送移除，草稿仍可在「待提交编辑」区重新附加。
- 旧修订卡片可 **恢复为新修订**（不调用模型，生成本地修订卡片）；编辑冲突时可从旧修订创建分支。
- 修订历史中可删除一条已记录修订：执行前需内联确认；初始渲染不可删，被更新修订当作基础引用的旧修订需先删更新那条。删除一条卡片正在渲染的修订时，客户端会先取回修订号更小、program 仍保留的最新一条修订作为回退目标，删除成功后让仍显示该修订的卡片回退到它（回退目标按会话保存在浏览器 `localStorage`，刷新后仍生效）；取不到回退目标时，该卡片自己渲染的修订不提供删除；会话内任一张卡有未发送编辑草稿时，对应基础修订都不能删除；仍被更新修订作为基础的修订会隐藏删除并说明原因。回退后的卡片只读；删除正在显示的修订后 stage 会选中确认文案里的回退目标，显示该目标时只读，选择其他修订即恢复可编辑；回退目标之后又被删除时，会沿回退链继续解析到仍存在的修订。其他仍显示该修订的卡片只有在回退目标可用时才会一并回退，否则可能变为 stale。删除是 Host 真删且不可恢复，对应的本地修订卡会一起移除，已生成的模型消息卡不会删除；返回 `revision_missing`（例如响应丢失后的重试）按已删除处理并刷新。
- 来源页面的临时样式会随内容编辑保留；纯排序/整体说明仍需要已保存/内置样式的页面。临时样式页面的自然语言样式调整在编辑画布的「样式 → 更改样式」区完成。

## 按需生成与模板

- 在 UI 面板选择 **按需生成**，正常发送需求即可；有重要歧义时模型会用结构化提问澄清。
- 生成结果可以先使用；点卡片「编辑」进入画布，在 **样式 → 更改样式** 区描述视觉调整或直接切换（版式由 Host 保持，内容变动只会告警，记录为新的临时样式修订）；只有带 theme 的临时样式结果卡底部才有 **保存为模板**，点击后保存布局、偏好和主题并创建新模板。旧 Host/不可编辑卡片仍保留底部「调整样式」回退按钮。
- 模板可以在 **插件详情页 → 我的样式** 或 Composer 的「显示样式」面板中导出/导入；导入只创建全局模板，需要显式阅读确认。

## 导出

回答底部操作栏最右侧的 **导出** 按钮可以：

- 导出该轮全部卡片为一张 PNG（原始 / 圆角 / 卡片；背景色与 1x/2x 在插件详情页设置）。
- 导出单文件 HTML，浏览器打开后继续交互；工作区本地图片会内联为 data URL，离线可看；`@ToAssistant` 会改为复制文案并提示回 DSH 粘贴。
