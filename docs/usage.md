# 使用指南

[English](usage.en.md) | [返回 README](../README.md)

本文是插件打开后的使用概览。实现细节、Host/Client 契约和完整边界见[架构与行为](architecture.md)。

## 打开开关

1. 在输入框右侧点 **UI** 控件，选择「仅本会话」；或发送 `/iui on`。
2. 正常情况下，下一条有结构的回答会在该轮末尾渲染成卡片。
3. 需要默认开启时，在 **插件详情页** 打开「在所有会话中启用」；全局设置只影响新会话。

开关关闭时模型看不到 `render_ui`，会直接回文字回答；重新打开即可。要强制出卡片（或模型仍然回了文字），可在开关已打开的会话里用 `/intelligent-ui` 显式调用技能。

## 提问

直接描述你要的页面和可交互部分，例如：

- 「帮我排一个上海两日游，要能勾选和调整」
- 「做一个 7 速自行车的换挡模拟器」
- 「把这几张表变成一个可以筛选的销售看板」
- 「介绍一下中国历史，要能按朝代展开」

有结构的回答默认使用卡片；长文/阅读型内容可以用 Article 样式。每次回答的样式可以在 **UI → 显示样式** 里按会话覆盖。

## 编辑已渲染页面

- 点卡片标题栏的 **编辑** 进入编辑画布；根层可编辑区块会有淡色轨道光晕。
- 左侧编排列表与画布双向 hover 联动。每行右侧的 **更多** 菜单提供定位、编辑、复制、移动到…和删除；删除在菜单内二次确认。
- 点区块填写修改要求并 **Save**，请求会进入待发送列表；也可以拖拽或键盘 ↑/↓/Home/End 调整顶层顺序。
- 画布上方的 **顶层 / 嵌套区块** 切换用于编辑容器内部（`Col`/`Row`/`Box`/`Grid`/`Card`/`Section`/`Carousel`）的区块。
- 面板顶部的 **调整样式** 区用一句话描述视觉调整（≤2000 字），与区块请求互斥；发送后模型保留内容与版式、只更新样式，记录为新的临时样式修订。支持新 Host 且可编辑的卡片不再显示底部「调整样式」按钮（旧 Host/不可编辑卡片保留回退）。
- `Divider`/`Spacer` 选中后是快捷调整：颜色/单位用插件自绘下拉，宽度/粗细/高度用插件自绘滑块，画布实时预览，应用后由 Host 记录修订，不调用模型。每个单位在行下和菜单里各带一句说明：默认表示不设置长度，px 是固定值，% 按容器比例（高度用 % 时父容器要有确定高度）。
- 复制/删除/移动等结构操作会先显示变更预览，确认后才记录修订；编辑中可开启 **严格保护**，拒绝未选中顶层区块的改动。
- 编辑 Header 的 **退出编辑** 关闭画布；卡片标题栏也有退出入口。每次编辑会话的请求以输入框 chip 携带，正常发送后才生成新修订。
- 旧版本渲染的卡片不需要手动迁移：第一次打开编辑、修订历史或恢复时，客户端会自动把当前渲染内容登记为 Host 的权威基础，之后结构操作、历史与恢复即可用。若部署的 Host 较旧或登记失败，相关操作会回退到指令编辑或提示重新渲染页面。

## 编辑请求、草稿与修订

- 每个被编辑的 Artifact 在输入框里有一个 chip：`编辑 {title} · 修订 N · {摘要}`。
- 同一聊天可保留多份草稿（单画布激活）；一次发送最多合并 3 个 Artifact 的请求，每个 Artifact 独立生成修订。
- 删除 chip 只会把对应草稿从本次发送移除，草稿仍可在「待提交编辑」区重新附加。
- 旧修订卡片可 **恢复为新修订**（不调用模型，生成本地修订卡片）；编辑冲突时可从旧修订创建分支。
- 来源页面的临时样式会随内容编辑保留；纯排序/整体说明仍需要已保存/内置样式的页面。临时样式页面的自然语言样式调整在编辑画布的「调整样式」区完成。

## 按需生成与模板

- 在 UI 面板选择 **按需生成**，正常发送需求即可；有重要歧义时模型会用结构化提问澄清。
- 生成结果可以先使用；点卡片「编辑」进入画布，在 **调整样式** 区描述视觉调整（保留内容与版式，记录为新的临时样式修订）；点卡片底部的 **保存为模板** 才会保存布局、偏好和主题。旧 Host/不可编辑卡片仍保留底部「调整样式」回退按钮。
- 模板可以在 **插件详情页 → 我的样式** 或 Composer 的「显示样式」面板中导出/导入；导入只创建全局模板，需要显式阅读确认。

## 导出

回答底部操作栏最右侧的 **导出** 按钮可以：

- 导出该轮全部卡片为一张 PNG（原始 / 圆角 / 卡片；背景色与 1x/2x 在插件详情页设置）。
- 导出单文件 HTML，浏览器打开后继续交互；`@ToAssistant` 会改为复制文案并提示回 DSH 粘贴。
