# 智能 UI

把回答渲染成可交互页面：行程、对比、看板、表单、文章，也支持聊天内按需生成和自定义视觉模板。

## 常用设置

- **输入框 UI 控件**与**回答样式**：在下方的全局默认里调整，会话级覆盖优先。
- **实验性功能 → 回答即文档**：默认关闭；开启后普通回答渲染为无卡片外壳的文档页面。
- **模板与样式**：在侧栏「智能 UI」面板管理；卡片右上角可编辑、查看修订或导出。

完整用法见 [README](https://github.com/Zephinel/dsh-intelligent-ui#readme)，架构与限制见 [docs](https://github.com/Zephinel/dsh-intelligent-ui/tree/main/docs)。
