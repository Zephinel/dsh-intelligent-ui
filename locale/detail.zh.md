# 智能 UI

解释类回答会在正文中直接内嵌可交互界面。需要独立页面时，回答末尾会生成可编辑的交互卡片（行程、对比、看板、表单或文章），同时支持聊天内按需生成和自定义视觉模板。

## 常用设置

- **输入框 UI 控件**与**回答样式**：在下方设置全局默认值，会话内的选择优先于全局默认。
- **正文内嵌 UI（默认）**：开启当前会话的 UI 开关后，普通解释会自动在需要处内嵌图表、表格与交互控件，无需额外开关。独立页面仍以可编辑卡片呈现。
- **实验性功能 → 回答即文档**：默认关闭。开启后，普通回答会改为无边框的整页文档。
- **模板与样式**：可在下方「我的样式」或输入框 **UI → 显示样式** 面板中管理。卡片标题栏提供区块编辑和修订历史，回答底部的导出按钮支持导出图片或单文件交互页面。

完整用法见 [README](https://github.com/Zephinel/dsh-intelligent-ui#readme)，架构与限制见 [docs](https://github.com/Zephinel/dsh-intelligent-ui/tree/main/docs)。
