# Intelligent UI

Explanations get interactive UI embedded right in the answer; ask for a standalone page and the plugin renders an editable card — itineraries, comparisons, dashboards, forms and articles, with chat-native on-demand generation and custom visual templates.

## Common settings

- **Composer UI controls** and **answer style**: adjust the global defaults below; per-session overrides take precedence.
- **Inline UI (the default)**: with the session UI switch on, ordinary explanations automatically embed charts/tables/interactions where they help — no extra switch; standalone pages still appear as turn-tail cards.
- **Experimental → answer as document**: off by default; when on, ordinary answers become a chrome-less document page at the turn tail.
- **Templates and styles**: manage them in the sidebar Intelligent UI panel; each card's header offers edit, revision history and export.

See the [README](https://github.com/Zephinel/dsh-intelligent-ui#readme) for usage and [docs](https://github.com/Zephinel/dsh-intelligent-ui/tree/main/docs) for architecture and limitations.
