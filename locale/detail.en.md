# Intelligent UI

Explanations embed interactive UI directly in the answer. When you ask for a standalone page, the answer includes an editable card for itineraries, comparisons, dashboards, forms, or articles. You can also generate layouts on demand and save custom visual templates.

## Common settings

- **Composer UI controls** and **answer style**: set global defaults below. Per-session choices in the composer override the global defaults.
- **Inline UI (default)**: when UI is on for the session, explanations embed charts, tables, and controls automatically. Standalone pages still render as editable cards at the end of the reply.
- **Experimental → Answer as a document**: off by default. When on, ordinary answers render as a document page without a card frame at the end of the reply.
- **Templates and styles**: manage saved templates under **My styles** below or in the composer's **UI → Display style** panel. Use the card header to edit blocks or open revision history, and use the export button in the message action bar to save a PNG or standalone HTML file.

See the [README](https://github.com/Zephinel/dsh-intelligent-ui#readme) for usage and [docs](https://github.com/Zephinel/dsh-intelligent-ui/tree/main/docs) for architecture and limitations.
