# Intelligent UI

Turn answers into interactive pages: itineraries, comparisons, dashboards, forms and articles, with chat-native on-demand generation and custom visual templates.

## Common settings

- **Composer UI controls** and **answer style**: adjust the global defaults below; per-session overrides take precedence.
- **Experimental → answer as document**: off by default; when on, ordinary answers render as a chrome-less document page.
- **Templates and styles**: manage them in the sidebar Intelligent UI panel; each card's header offers edit, revision history and export.

See the [README](https://github.com/Zephinel/dsh-intelligent-ui#readme) for usage and [docs](https://github.com/Zephinel/dsh-intelligent-ui/tree/main/docs) for architecture and limitations.
